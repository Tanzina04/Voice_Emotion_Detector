Project Architecture

AuraVoice is an interactive web-based Artificial Intelligence demonstrator. It uses digital signal processing (DSP) to extract acoustic feature dimensions from human speech recordings and passes them through an optimized machine learning classifier to perform real-time speech emotion recognition.

Key Features

📁

Drag & Drop Upload

Upload WAV, MP3, OGG, FLAC, M4A, MP4, AAC, WMA and more directly into the glassmorphic dropzone with instant format validation.

🎙️

Browser Mic Recording

Record voice streams in real-time. High fidelity canvas frequency-spectrum rendering displays active voice levels.

📊

Dynamic Visual Charts

Deep probability breakdowns mapped in horizontal confidence tables. Emojis and indicators style the final report.

🧠

SMOTE Balanced Models

Trained on the RAVDESS speech database with Synthetic Minority Over-sampling to prevent bias across emotional categories.

How It Works

1

Acoustic Signal Intake

User inputs a voice segment (either via file drag-and-drop or direct browser microphone capture).

2

Feature Vector Extraction

Librosa processes the digital waveform, generating 54 acoustic features: 40 Mel-Frequency Cepstral Coefficients (MFCC), 12 Chroma pitch class profiles, 1 Zero Crossing Rate (ZCR), and 1 Spectral Centroid.

3

Normalization & Classification

A StandardScaler standardizes the variables, which are then evaluated by our classifier model to predict class labels and output probability confidence arrays.

Technologies Used

Python Flask (Backend) Librosa (Audio DSP) Scikit-learn (ML Engine) SMOTE (imblearn) HTML5 Web Audio API Chart.js (Visuals) CSS Grid & Flexbox
